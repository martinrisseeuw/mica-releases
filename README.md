# Mica for macOS

A minimal browser with spaces, pinned tabs, Chrome DevTools, and Chrome extensions.

[Download the latest Mica installer](https://github.com/martinrisseeuw/mica-releases/releases/latest)

Requires an Apple Silicon Mac and macOS 13 or later. Drag Mica into Applications
for the first installation. Releases are Developer ID signed and notarized by Apple.

From version 0.2.8 onward, Mica checks for updates automatically, downloads signed
updates, and installs them when you quit. Use **Mica → Check for Updates…** to
check immediately, or toggle **Automatically Keep Mica Up to Date** in that menu.

An older version needs one installation of 0.2.8 or later to enable the updater.
Updates preserve the browser profile, spaces, pins, extensions, and website data.

This repository distributes release installers and the signed Sparkle update
feed. It does not contain the browser's source code or any browser profile data.

[Mica source code, issues, and contributions](https://github.com/martinrisseeuw/mica)
